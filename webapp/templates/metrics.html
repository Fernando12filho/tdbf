1 · BRT quality Phase A · C2P = F2P / (F2P + F2F)

How a generated test behaves on buggy code → gold-fixed code:
F2P Fail → Pass (= L4) — reproduces the bug and the gold fix clears it. The only valid BRT.
F2F Fail → Fail (= L3) — catches a failure, but the gold fix doesn't clear it (wrong assertion).
C2P (candidate→plausible) = F2P / (F2P + F2F) = L4/(L3+L4). L0–L2 = the test never ran cleanly on buggy code (malformed / crashed), so it forms no transition. (SWE-bench Pass→Pass is the held-out regression suite, not a generated BRT — not shown here.)
