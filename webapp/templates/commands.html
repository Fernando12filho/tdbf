Commands & instructions

Run everything from the project root. Live runs (anything that touches Docker or a hosted model) need both the Docker socket and your API keys exported first — see Environment. Offline smoke tests need neither.

macOS + Colima. The Ollama server is the Windows desktop at 192.168.1.192:11434.

3. Offline tests (no Docker, no API key, no cost)

Validate the pipeline wiring before spending anything.

{{ cmd("python3 scripts/00_smoke_test.py # end-to-end offline pipeline\npython3 scripts/agent_runtime_smoke.py # tool-use loop + message conversion\npython3 scripts/agent_tools_smoke.py # tool layer + gold-free guard\npython3 scripts/agent_brt_smoke.py # Phase A orchestration glue\npython3 scripts/agent_fix_smoke.py # Phase B fix-agent glue\npython3 scripts/agent_pipeline_smoke.py # end-to-end BRT->fix glue") }}

4. Build the Docker eval image (required before any live run)

Builds sweb.eval.x86_64.<instance_id>:latest and validates the gold patch.

{{ cmd("# One instance\npython3 scripts/01_validate_gold.py --split lite --id astropy__astropy-12907\n\n# Whole split (slow)\npython3 scripts/01_validate_gold.py --split lite") }}

5. Phase A — BRT agent (write a bug-reproduction test)

Writes a BRT, scores L0–L4 offline behind the gold barrier, logs to results.jsonl + runs/agent_brt/<id>.json.

{{ cmd("# Single instance, Claude Sonnet\npython3 scripts/04_agent_brt.py --id astropy__astropy-12907 --model anthropic:claude-sonnet-4-6 -v\n\n# Weak baseline (qwen via Ollama) — RQ1\npython3 scripts/04_agent_brt.py --id astropy__astropy-12907 \\\n --model \"ollama:qwen2.5-coder:7b-instruct-q4_K_M@http://192.168.1.192:11434\" -v\n\n# Prompt-hardening (RQ1 scaffolding ladder; applies to both models)\npython3 scripts/04_agent_brt.py --id django__django-10914 \\\n --model anthropic:claude-sonnet-4-6 --prompt-harden -v\n\n# First N instances of the split\npython3 scripts/04_agent_brt.py --limit 5 --model anthropic:claude-sonnet-4-6") }}

Useful flags: --max-iterations 20 · --max-tokens 200000 · --think (qwen3 reasoning) · --keep-container · -v (stream the tool trace).

6. Phase B — Fix agent (fix until the BRT passes)

Needs a validated L4 BRT for the instance in results.jsonl (run Phase A first). Scores resolved via the official SWE-bench harness behind the gold barrier.

{{ cmd("# Single instance, Claude Sonnet (BRT pulled from results.jsonl)\npython3 scripts/05_agent_fix.py --id astropy__astropy-12907 --model anthropic:claude-sonnet-4-6 -v\n\n# Weak baseline (qwen)\npython3 scripts/05_agent_fix.py --id astropy__astropy-12907 \\\n --model \"ollama:qwen2.5-coder:7b-instruct-q4_K_M@http://192.168.1.192:11434\" -v\n\n# Supply a specific BRT file instead of the results.jsonl lookup\npython3 scripts/05_agent_fix.py --id astropy__astropy-12907 \\\n --brt-file runs/agent_brt/astropy__astropy-12907.json --model anthropic:claude-sonnet-4-6 -v") }}

Useful flags: --max-iterations 20 · --max-tokens 300000 · --keep-container · -v.

7. End-to-end pipeline (BRT → fix in one command)

Runs Phase A then, only if the BRT is validated L4, hands it in memory to Phase B — no results.jsonl round-trip. Writes the same two records as running 04 then 05 (this dashboard shows both).

{{ cmd("# One instance, end to end (build the image first, step 4)\npython3 scripts/06_agent_pipeline.py --id astropy__astropy-12907 \\\n --model anthropic:claude-sonnet-4-6 -v\n\n# First N instances of the split\npython3 scripts/06_agent_pipeline.py --limit 5 --model anthropic:claude-sonnet-4-6\n\n# Stop after Phase A (write the BRT, skip the fix)\npython3 scripts/06_agent_pipeline.py --id astropy__astropy-12907 \\\n --model anthropic:claude-sonnet-4-6 --brt-only -v") }}

The model is shared by both phases. Flags: --max-iterations 20 (per phase) · --max-tokens 300000 (per phase) · --brt-only · --prompt-harden · --keep-container · -v.

8. Non-agentic baseline (workflow, for comparison)

The fixed-loop --attempts/--repair pipeline that predates the agents.

{{ cmd("# Two-phase generation (observe buggy output, then write the test)\npython3 scripts/02_generate_brt.py --id astropy__astropy-12907 \\\n --model anthropic:claude-sonnet-4-6 --observe --attempts 3\n\n# Batch over the split\npython3 scripts/03_batch_brt.py --model anthropic:claude-sonnet-4-6 --observe --attempts 3") }}
